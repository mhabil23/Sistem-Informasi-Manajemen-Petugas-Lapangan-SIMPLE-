# Laravel Application - SIMPLE Project Guidelines

## Project Overview
Sistem Informasi Manajemen Pelayanan & Evaluasi Lapangan (SIMPLE).
Aplikasi terintegrasi untuk pendataan sensus / survei lapangan, administrasi dokumen Berita Acara Serah Terima (BAST Responden & Petugas), Laporan Perjalanan Dinas, dan Rekapitulasi Progres.

## Sisi Petugas (Mobile-First)
- Dashboard sederhana (HP): Notifikasi deadline/status & 4 Menu Tombol Utama.
- Form BAST Responden: Pemilihan sampel responden (warna hijau bila selesai), opsi penerima (KRT vs Wakil), tanda tangan digital canvas.
- Laporan Kegiatan / Perjalanan Dinas: Form laporan + auto generate PDF.

## Sisi Admin (Desktop Monitoring & Rekap)
- Dashboard Progres & Monitoring:
  - Rekap penyelesaian BAST (Target, Realisasi, Persentase).
  - Filter progres per Kecamatan atau per Petugas.
  - Identifikasi petugas yang belum selesai/lambat untuk keperluan follow-up / notifikasi.
  - Monitoring pengumpulan laporan perjalanan dinas petugas (Total Petugas vs Sudah Lapor).
  - Bulk print & tabel rekapitulasi.
